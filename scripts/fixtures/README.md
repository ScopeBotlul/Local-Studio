# Native playback fixture

`colors-vp8.webm` is a 320×180 VP8 recording of alternating solid-color canvas frames, generated by this project's test harness. No user media or model output. It was decoded and played by the real Windows app in the 0.20.0 regression run.

Reuse these actual video bytes for project/gallery playback tests: recording a new canvas inside an occluded WebView can otherwise produce a header-only file because Windows suppresses capture frames. Playback, restricted protocols, byte preservation and metadata assertions still exercise the real application.
