# Local Studio 0.35.3

## Fehlerbehebung

- Prüfung und Entpacken des offiziellen ComfyUI-Archivs laufen unter Windows jetzt ohne sichtbares `System32\tar.exe`-Konsolenfenster.
- Der Vorgang ist weiterhin aktiv, während der Einrichtungsdialog **ComfyUI wird installiert …** zeigt. Besonders das 1,6-GB-AMD-Paket kann nach dem Download für einige Zeit geprüft und entpackt werden.
- Download, offizieller SHA-256-Vergleich, sichere Archivpfadprüfung und Zielstruktur bleiben unverändert.

## Aktualisierung

Installiere Local Studio 0.35.3 und starte den AMD-ComfyUI-Download erneut. Während der Archivverarbeitung bleibt alles im Local-Studio-Fenster; es muss kein Konsolenfenster geschlossen oder bedient werden.
